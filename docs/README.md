# myCart Documentation

This directory contains all documentation for the myCart project, organized by type.

## Directory Structure

```
docs/
├── README.md                    # This file
├── swagger/                     # API documentation (Swagger/OpenAPI)
│   ├── index.html              # Swagger UI
│   ├── swagger.json            # Generated OpenAPI spec
│   ├── swagger.yaml            # Generated OpenAPI spec (YAML)
│   ├── docs.go                 # Generated Go code
│   └── swagger-setup.md        # Setup instructions
├── e2e/                        # E2E test reports
│   ├── admin/                  # Admin panel E2E reports
│   └── site/                   # Storefront E2E reports
└── *.md                        # Markdown docs for Solidebase

```

## Documentation Types

### API Documentation (Swagger)

Located in `docs/swagger/`, generated from Go code annotations using [swaggo/swag](https://github.com/swaggo/swag).

**Local development:**
```bash
# Regenerate after API changes
swag init -g cmd/main.go --output docs/swagger --parseDependency --parseInternal

# Start server with Swagger UI
go run ./cmd serve --dev

# Access at http://localhost:8080/swagger/
```

See [swagger/swagger-setup.md](swagger/swagger-setup.md) for details.

### E2E Test Reports

Located in `docs/e2e/admin/` and `docs/e2e/site/`, generated by Playwright tests.

**Generate reports:**
```bash
# Run E2E tests for admin panel
cd web/admin && bun run test:e2e

# Run E2E tests for storefront
cd web/site && bun run test:e2e
```

Reports are HTML files viewable in browser.

### Markdown Documentation (Solidebase)

Root-level `*.md` files in `docs/` are processed by Solidebase (mdx-sitegen-solidbase) to generate the main documentation site.

## GitHub Pages Deployment

All documentation types are automatically deployed to GitHub Pages via `.github/workflows/deploy-docs.yml`:

1. **E2E reports** generated from Playwright tests
2. **Swagger documentation** generated from Go code
3. **Solidebase docs** generated from markdown files

The workflow runs on push to `main` and can be manually triggered via `workflow_dispatch`.

Access the deployed documentation at: `https://<username>.github.io/<repo>/`

## Adding New Documentation

### API Endpoints

Add Swagger annotations to Go handlers:

```go
// @Summary     Short description
// @Description Detailed description
// @Tags        category
// @Accept      json
// @Produce     json
// @Param       id   path      int  true  "Item ID"
// @Success     200  {object}  ResponseType
// @Router      /api/endpoint/{id} [get]
func Handler(c fiber.Ctx) error {
    // implementation
}
```

Then regenerate: `swag init -g cmd/main.go --output docs/swagger --parseDependency --parseInternal`

### Markdown Docs

Create `*.md` files in `docs/` directory. Solidebase will process them during deployment.

### E2E Tests

Add Playwright tests in `web/admin/tests/` or `web/site/tests/`. Reports are automatically generated on CI.
